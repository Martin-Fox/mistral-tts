# AI Rules

## 0. Mandatory workflow
Before solving ANY task:
1. Read /ai_light/PROJECT.md
2. Summarize relevant parts in 2–4 bullets
3. Then proceed

If something is unclear → ask questions BEFORE coding

---

## 1. Understand first
- Never assume missing details
- Restate the goal before implementing
- Ask clarifying questions if needed

---

## 2. Simplicity first
- Prefer simplest working solution
- No unnecessary abstractions
- No new dependencies without justification

---

## 3. Surgical changes
- Modify only what is necessary
- Do not refactor unrelated code
- Preserve structure unless explicitly asked

---

## 4. Verification
- Do not say "fixed" without explanation
- Explain WHY the solution works
- Consider edge cases

---

## 5. Task execution

### Bug fixing
1. Understand the bug
2. Identify root cause
3. Apply minimal fix
4. Explain why it works

### New features
1. Clarify requirements
2. Check impact on existing code
3. Implement smallest working version

### Refactoring
- Only if explicitly requested
- Never mix with feature work

---

## 6. Alignment check (REQUIRED)
After solution:
- Explain how it follows PROJECT.md
